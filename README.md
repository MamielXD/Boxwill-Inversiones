# Boxwill Inversiones

Sistema integral de gestión de inversiones, préstamos y patrimonio con panel de administración y control de flujos de caja.

## Demo

[Ver proyecto](https://inversiones.boxwill.com/)

## Tecnologías

- Astro
- React
- Tailwind CSS
- PHP (Backend / API)
- MySQL

## Funcionalidades

- Panel de control de inversiones con cálculo automático de ROI y rentabilidad anual/mensual.
- Gestión de préstamos, cuotas y cálculo de intereses.
- Control de inventario de herramientas, repuestos y consumibles, incluyendo modo de "despiece".
- Gestión de caja, rendimientos y cuentas bancarias integradas.
- Gráficos interactivos de distribución y evolución del portafolio.

## Instalación

```bash
git clone https://github.com/MamielXD/Boxwill-Inversiones.git
cd Boxwill-Inversiones
npm install
npm run dev
```
